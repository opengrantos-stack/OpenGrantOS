# OpenGrant OS Roadmap

## Phase 1 — Foundation (Current)

Status: In Progress

Objectives:

- Define product architecture
- Create project documentation
- Research Web3 grant ecosystems
- Prepare MVP specifications
- Build initial community presence

Deliverables:

- README documentation
- Product Requirements Document
- Grant Proposal
- Initial project structure

## Phase 2 — MVP Development

Status: Planned

Objectives:

- Develop the first working version of OpenGrant OS
- Create user authentication system
- Implement project profiles
- Build grant discovery features
- Add application submission workflow

Deliverables:

- Functional MVP
- Basic user dashboard
- Grant database
- Application management system

- Wallet connection

Status: Future

OpenGrant OS aims to become an open-source infrastructure layer that improves how innovation is funded across the Web3 ecosystem.
